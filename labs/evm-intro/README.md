# Introducción a EVM

El módulo se abre desde la primera tarjeta del dashboard o en `/#evm-intro`. Las ocho secciones de [lesson.js](lesson.js) incluyen una explicación, una pregunta con tres opciones y una referencia. Los ejemplos del taller y los ejercicios numéricos se elaboraron para CryptoGuard.
